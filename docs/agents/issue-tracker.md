## 记录约定

- 任务规格保存在 `docs/plans/`，包含目标、状态、授权来源、范围、验收和执行记录。
- 开始时改为进行中；完成后记录实际产物、验证、遗留事项与提交依据，不将“已批准”写成“已完成”。
- 新增有依赖的任务时明确前置任务，不借任务拆分扩大原授权。
- 需要更细工单时在对应任务目录维护 Markdown 文件，并在本页提供入口；不要迁入旧工程 Ticket 编号或状态机。
- 文档初始化验收见[实际检查记录](../validation/repository-initialization-2026-09-06.md)。
