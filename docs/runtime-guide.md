# Windows 真实运行版本

本页描述 `feat/movie-runtime`。这是正在验证的本地实现，完整电影能力的完成状态见[实施记录](./plans/runtime-implementation.md)。

## 初始化和启动

依赖 Python 3.12、uv 和可访问所选模型服务的网络。仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

默认浏览器地址是 `http://127.0.0.1:4318`。更换端口使用 `start.ps1 -Port 4319`。原型仍可在 4317 独立运行，不与真实版本共享项目数据。关闭浏览器不会停止服务；关闭启动终端会停止本地服务，重新启动后会恢复有任务身份的云端查询。

初始化使用锁定依赖；FFmpeg 安装在本仓库 `.cache/tools/ffmpeg`，下载后核对 Gyan 发布的 SHA256，保留随包许可。也可设置 `MOVIE_FFMPEG` 为现有 FFmpeg 的可执行文件。当前不提供安装包。

## 模型与密钥

打开“模型设置”，添加服务连接，填写接口类型、Base URL、API Key，再按服务商提供的模型 ID 添加模型并分配用途。首次配置为空，不预置所有者个人组合。

Key 仅写入当前 Windows 用户的凭据管理器，服务名为 `movie-agent.local.api`。页面只显示是否保存，不回读旧 Key。连接、模型和用途等非秘密配置保存在本地数据库；`.env.example` 仅为历史空字段说明，运行时不读取它。

“保存”“检查已保存连接”“获取模型”和实际生成分别执行。对话接口读取模型列表；H3 读取任务列表；声音接口读取系统音色。只读检查成功不能证明所有模型有生成权限。其他专用协议明确显示尚未适配。

当前实现的协议包括 OpenAI 兼容对话与文生图、方舟图片与视频、MiniMax 视频 V2 与声音 V1。可填模型 ID 不意味着所有模型参数都兼容；实际生成结果需按模型验证。缺少某用途只影响相应步骤。

本轮 MiniMax 配音已有真实 WAV。music-3.0 接口返回 HTTP 410，说明不再向新用户开放；没有据此宣称音乐生成成功。需要具备可用的独立配乐服务才能完成该项验收。

## 创作和修改

从一句想法开始，导演会提问或提出故事方案。共创的关键产物在对话和右侧作品页提供审核；托管按已经给出的范围推进。专业任务与媒体在后台执行，完成后进入导演收件箱。

点击回复旁的“查看执行过程”或顶部“运行记录”，查看实际模型请求、工具活动、专业任务和媒体状态。运行记录会更新，也会在刷新后恢复；旧运行没有采集的详情不会补造。工具调用完成仅表示该次调用返回，生成任务仍可能在云端执行。输入／输出 tokens 是累计调用用量，不是当前上下文占用。

左侧可以搜索影片，点击顶部片名可以重命名。右侧按标签切换作品，拖动分隔条或聚焦后按左右方向键调整宽度。未发送文字按项目保留在当前浏览器会话中；刷新会恢复已打开标签，页面内切换作品会保留阅读与播放位置。Enter 发送、Shift+Enter 换行、Ctrl+K 新建影片、Ctrl+S 保存正在编辑的草稿。外观支持跟随系统、日间和夜间。

剧本编辑器保存独立草稿，保存不会触发制作。提交会建立快照并交给导演理解，随后由具体修改方案和当前授权决定制作。发生版本冲突时会保留内容，不能用刷新强行覆盖手改。

剧本版本默认展示原文，“编辑草稿”进入单独的“剧本草稿”标签；已有手改不会被其他版本替换。状态会区分未保存、已保存但未提交、已提交及冲突。网络保存失败可以重试；真正的版本冲突会保留编辑内容并提供复制入口。切换模式、等待审核与媒体暂停是不同状态，临时口头委托的范围仍以对话为准，当前没有任意范围的授权看板。

顶部“资产库”打开右侧固定标签，只收录当前对话所属电影项目的全部产物，可按文稿、图片、视频镜头、声音、成片与母版筛选。资产包括中间产物和历史版本；搜索与分类按项目记住，切换到单个资产后可直接返回。对话仅保留最近三项的快捷入口及总数，新产物通过现有事件自动收录，不改变正在查看的标签。

真实视频可播放、下载和标注。标注进入对话输入区，可多条一起发送或逐条发送，始终绑定原视频版本。“从此版本继续”是明确采用动作，单纯浏览旧版本不改变采用状态。完整任务、失败原因与核对结果入口位于“运行记录 → 媒体任务”；没有生成出产物的失败任务不会被伪装成资产。

后期保留生成源文件、无字幕画面母版、原生混合声音、独立配音／配乐和字幕。只换声音时复用画面母版。原生对白与环境声若混在一起，不能当作独立音轨修改；涉及表演和口型的改动需补拍。

仅改导出规格时，导演可用 `export_film_version` 保留来源影片的完整剪辑、独立声音和字幕，不重新抄写轨道。镜头原生声与包含同一批镜头的混合声不能重复叠加；原生混合声也不等于加入独立配音后的完整声音。

当前生成规格为 **H3 768P、Seedance 720P**，本轮个人 Seedance 已改用 **2.0 Fast**，模型 ID 由已配置方舟连接的只读模型列表核对。成片导出为 **720P、16:9、24 fps、48 kHz**。提交前按实际接口校验生成分辨率。旧高分辨率素材及已提交云端任务保留，导出时本地缩放；旧画面母版派生新的 720P 母版，历史文件不会覆盖。原始与输出尺寸分别记录在元数据中。

## 中止、恢复和本地数据

“中止”立即阻止后续调度并停止本地执行。H3 不调用兼具删除语义的 DELETE；已经提交的云端任务仍会查询和保存为候选，不自动覆盖新版本。页面会如实显示这些状态。

外部提交丢失响应时标为结果不明，不自动重发。拿到任务身份后可恢复查询；已有结果仅重试下载。若没有身份，需要先在服务商记录中核对对应任务。不能把重新生成当作恢复。

“结果已生成 · 下载受阻”和“云端状态查询受阻”都保留原任务身份，可以核对与恢复，不因取文件失败重拍。Windows 本机代理使用 fake DNS 时，仅已识别的 Provider 文件域名可经该显式本机代理解析下载；其他本地／保留网络仍拒绝。不会关闭浏览器同源保护，也不会向媒体下载站点发送 API Key。

可以用 `scripts/export_validation.py` 导出项目用量、任务时间与复用身份到本地 JSON；缺少账单金额仍记为待核对。实际证据与未完成项见[运行验证记录](./validation/runtime-evidence-2026-09-06.md)。

默认数据位于忽略目录 `local-data/`：`films.sqlite3` 管理电影记录，`agents.sqlite3` 保存 AgentScope 会话，`media/` 保留产物。备份或迁移时关闭服务，再备份整个目录；Key 不在这些文件中，换 Windows 用户后需要重新配置。

服务只监听回环地址，拒绝跨站写入；媒体通过产物身份读取，不接受任意文件路径。推理与媒体生成会把必要文本及参考内容发送给用户配置的服务，不能作为完全离线软件使用。

## 先看分镜预演

采用剧本后，可以对导演说“先用已有构图和临时声音做一段分镜预演，看看事件是否讲清楚”。导演需要制作说明、实际图片和声音；本地合成不会再次调用生成API。缺少素材时，先按当前共创／托管范围制作素材。

预演保存在当前对话资产库的“预演、成片与母版”分类，可播放、下载并按时间点标注。它带有静态预演标识，不能作为真实试拍或完整成片采用；已有声音不代表口型、表演和试听已通过。时长以24fps实际画面边界对齐，源图、临时声音和制作说明都能追溯。

2026-09-09的隔离验证、调用数量及已发现的参考遗漏见[实际记录](./validation/preproduction-live-2026-09-09.md)。该开发数据与默认 `local-data` 下的用户项目分开；验证中的样本不代表未经引导的全程托管达标。
