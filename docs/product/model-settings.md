# 模型与 API 设置

Date: 2026-09-06

Status: confirmed_direction_prototype_implemented

## 用户决定

初始设置不包含固定服务商或模型。用户提供自己的 API 连接和模型选择；此前 GLM、H3、Seedream、Seedance 的组合属于所有者个人使用及验证计划。决定依据见 [ADR 0004](../adr/0004-user-configured-models.md)。

## 界面结构

“服务连接”管理一组连接，支持添加、编辑、删除；每个连接包含：

| 字段 | 含义 |
|---|---|
| 连接名称 | 用户自定义标签，便于辨别不同账号或服务 |
| 接口类型 | 声明接入协议；原型展示 OpenAI 兼容与其他／专用接口，专用接口仍需相应适配器 |
| API 地址 · Base URL | 按服务商文档填写，包括必要的版本路径；不自动套入某个厂商地址 |
| API Key | 可输入并显隐；也可声明该连接无需 Key，例如无需鉴权的本地服务 |
| 模型列表 | 手动填写模型 ID、可选显示名称及能力；有相应发现接口时可获取列表 |

一个连接可添加多个模型。同一个模型 ID 如需声明多种能力，可分别添加不同能力项；这些是用户声明，不是能力验证结论。

“用途分配”从已保存的连接和模型中选择导演／对话、图像、视频、备选视频、配音、配乐及音效所用模型。默认全部未设置；按已声明能力筛选候选。修改、移除模型或删除连接后清理失效引用，不悄悄换用别的模型。产品不要求用户一次填完所有配置才能开始表达创作想法。

检查连接、获取列表和保存配置是独立操作。保存不触发模型调用或生成；原型填写任意名字不会改变既有示例导演回复或试拍。未保存的表单内容不构成生效配置。

## 当前原型与正式接入

- 检查连接可演示成功或失败；获取模型仅在用户点击时加入可编辑的示例 ID，默认列表为空，未请求真实服务。
- API Key 不进入可序列化项目状态、localStorage、日志、截图或仓库；只在当前页面内存中暂存，刷新后重新输入。默认遮罩，测试仅使用伪造示例值。
- 服务名称、接口、基础地址、模型列表和用途分配保存到当前浏览器。地址检查拒绝嵌入账号密码、查询参数或 fragment，避免把凭据当成配置地址保留；仍不冻结正式 URL 与鉴权适配规则。
- 正式产品需独立完成凭据存储、协议适配、实际连接检查与模型能力验证。对话接口兼容不能推出该服务的媒体 API 兼容；图片、视频和异步查询各按实际接口接入。
- 当前交互不决定最终运行 API、Schema、模型注册机制或支持厂商列表。

## 研究依据与吸收

本轮查阅官方资料，吸收配置结构，未复制其代码：

- [Open WebUI：Connect a Provider](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/) 通过 URL 与 Key 添加连接，并可发现模型；同时区分连接协议。采用连接与模型分开的方式，不照搬其全部支持能力。
- [Cherry Studio：Model Provider Settings](https://docs.cherry-ai.com/cherry-studio-wen-dang/en-us/cherry-studio/preview/settings/providers) 及[手动添加模型示例](https://docs.cherry-ai.com/pre-basic/providers/doubao?open_in_browser=true)展示 API 字段与模型 ID 管理。本轮搜索索引可读取相关内容，直接打开页面失败，故仅用于字段与手动添加方式的旁证。

用途分配是本项目面对多种 AIGC 能力的产品选择，不将其归因于上述工具已经提供相同电影工作流。
