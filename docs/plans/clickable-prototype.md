## 目标与入口

验证 AIGC 零基础用户能否通过对话、作品侧栏和少量必要控件完成创作、审核与修改。以 Windows 桌面浏览器为验收环境，保留 A 日间／B 夜间设计方向。

- 左侧可收起的影片列表，中央主导演对话，右侧可收起的多标签作品页，一次显示一个内容。
- 新影片首屏以一句话想法为入口，示例点击填入输入框但不自动发送；首条消息建立影片项目。
- 首次配置提供模型 API Key 设置和连接检查的交互演示；原型仅使用示例凭据与模拟检查结果，不读取真实密钥、不发模型请求。
- 2026-09-06 用户审阅修正：模型设置采用通用服务连接、模型 ID 与用途分配，不预设厂商或模型；之前的固定模型属于所有者个人使用选择。输入字段可编辑，原型 Key 仅留页面内存，详见[设置规格](../product/model-settings.md)。
- 主题默认跟随系统，可手动切换并记住选择；C 方案不采用。

## 必须可操作的路径

| 路径 | 预期交互 |
|---|---|
| 共创与托管 | 输入框旁显示有效模式与部分托管摘要；演示修改授权后控件和对话一致 |
| 故事与作品 | 从对话作品入口打开提案、剧本、图片、视频；首份作品可自动展开，主动收起或正在查看内容时保留用户选择 |
| 剧本编辑 | 编辑自动保存草稿，显示未提交状态；提交后进入导演理解与修改建议；保存本身不改视频 |
| 审核 | 显示具体内容、版本、建议和下一步；按钮或文字确认推进同一轮示例流程，修改意见仍在对话中给出 |
| 视频与标注 | 可播放明确标识的示例动态内容，在时间点添加、编辑、移除标注；回到输入框后可单条／批量发送并附整体要求 |
| 版本 | 查看历史作品并切换标签；浏览不改变采用版本；明确从旧版继续时保留当前稿与未提交改动 |
| 制作期间 | 输入框保持可发消息；独立中止按钮演示正在停止／已停止，保留已有对话与作品 |
| 异常恢复 | 通过正常文字说明受阻与建议，用户用自然语言回应；模拟状态与真实生成区别明确 |
| 返回项目 | 可切换影片并恢复其对话与作品；刷新可恢复示例项目状态。服务后台持续运行能力在真实运行时验证 |

演示故事可使用“最后一束光”，与已认可静态参考保持关联。示例不预设所有真实电影必须采用相同场景数、步骤或镜头。

## 实现与素材边界

原型实现记录其实际技术选择，不据此冻结电影运行 API、数据库、最终前端复用或 Agent 数量。使用自有示例文稿、演示素材及明确标注的状态，保存原始视觉参考出处。

不接入真实模型、不制造真实生成通过率或媒体质量结论。模拟连接成功、停止完成或恢复成功仅说明交互状态可演示；不得写成生产服务已具备相应能力。

## 验收与交付

- 在实际浏览器完整操作上述路径，同时检查日间／夜间、侧栏展开收起和常见桌面宽度；不要求手机完整流程验收。
- 重点检查草稿与采用版本、标注与发送、历史查看与恢复、停止请求与完成状态是否被正确区分。
- 提供可打开的本地入口、必要启动说明、代表性截图和实际验证记录；没有做过的检查标为未执行。
- 用户审阅原型后记录具体反馈；浏览器技术检查通过不等于用户已接受产品体验。
- 如原型实现发现会改变已确认语义的问题，说明具体冲突；普通排版与可逆细节自行落实，不逐项要求用户表决。

## 实际交付 · 2026-09-06

- 回答的问题：三栏对话与作品标签页，能否清楚表达共创／托管、草稿／提交／采用、标注／发送和历史查看／恢复？用户后续已暂定通过 UI，见末节。
- 代码：[prototype](../../prototype/README.md)，独立分支 `prototype/film-creation`；基线 `77a1cc08bc5e9901a31dfd728997823695f7c56e`。原型不合并为正式电影运行时。
- 启动：仓库目录执行 `npm run dev`，访问本机 4317 端口，无 npm 运行依赖。
- 实现：原生 HTML、CSS、JavaScript 与 Node.js 静态服务；浏览器 localStorage 保留示例状态。代码、示例状态结构与定时流程不冻结正式架构、数据库或模型决策规则。
- 媒体：原创 Canvas 动态示意与合成环境低鸣，可播放、拖动、标注；不使用参考电影素材，不接入真实生成。示例声音反馈更新版本与文字，不模拟已实现真实配乐编辑效果。
- 检查：[浏览器验证](../validation/clickable-prototype-2026-09-06.md)。原型关闭页面后没有后台任务执行，刷新会明确停止上一次计时演示并保留已有内容；正式后台恢复另行实现。
- 下一步：[真实电影能力建设](./capability-mvp.md)，以真实产物和修改推进；AgentScope／ViMax 模块接入及整片人评分别验证。

## 用户审阅后的设置修正

用户对整体原型表示“感觉还行”，并明确要求取消产品级模型预设。已据此改为通用 API 连接、模型列表及用途分配，更新产品基线、开发助手规则与空配置示例。设置检查时尚待用户审阅，实际检查见[模型设置验证](../validation/model-settings-2026-09-06.md)。
