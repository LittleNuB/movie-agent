## 本轮范围

- 对话优先的精简三栏：可收起项目导航、流式对话、可调宽度的多标签作品侧栏，每次只显示一个作品。
- 正常 Markdown 排版、复制消息、输入草稿按项目保留、明确发送失败、连接状态、滚动时不抢阅读位置、回到最新消息、基础键盘操作。
- 真实活动：模型请求、工具准备／执行／结束、专业协作、媒体任务；可展开、刷新可恢复、显示等待或失败，不能伪造进度、隐藏思维链或把工具提交完成当云端生成完成。
- 项目搜索和重命名；导演通过真实命名工具落地，不仅回复承诺。
- 独立草稿使用专属标签；历史与待审核文稿默认读原文；保存／未提交／已提交／冲突明确呈现。创建草稿不能覆盖已有改稿。
- 作品搜索和按类型筛选、时间、版本与当前采用标识；图片、声音、影片、母版可访问；标注跳转源影片时间，批量发送保留绑定关系。
- 审核入口明确内容和动作；创作模式、审核等待与停止状态分别解释；仅呈现实际记录的授权，不猜测自然语言范围已进入结构化授权。
- 系统／日间／夜间主题；桌面1366、1600宽度可用；不引入时间线工作台或替换运行框架。
