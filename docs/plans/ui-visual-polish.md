## 目标

为Movie Agent建立可识别的Logo与统一视觉语言，改善当前字母M占位标志、欢迎页和工作区的视觉完成度。保持已确认的日间／夜间主题、对话布局、资产库与多标签作品侧栏；仅保留共创、托管两种模式。

## 下一轮实施范围

1. 根据用户反馈收敛Logo，制作SVG主标志、字标组合、反白版与浏览器图标；在16／24／28／44px实际尺寸核对轮廓与留白。
2. 统一侧栏品牌区、收起导航时的标志、欢迎页与浏览器标签；欢迎页围绕开始创作组织视觉重心。
3. 调整字体层级、行距、间距、分隔线、按钮与选中状态，统一项目列表、对话、输入区、资产库和作品标签的视觉密度。
4. 日间与夜间分别核对可读性、媒体预览和状态辨识；必要的过渡反馈遵循减少动态效果偏好，运行状态继续来自真实事件。

## 验收

- 首先在实际页面比较品牌区和欢迎页，再核对已有项目、资产库、剧本编辑和视频预览。
- 1366px与1600px桌面宽度下检查导航开合、作品侧栏和长标题；保留原有输入、标注、版本与播放体验。
- Logo选型与视觉人评由用户反馈，功能检查单独记录；不以设计稿代替浏览器结果。
- 这轮视觉工作不需要重新生成电影素材。前期制作的逻辑、选材和托管质量缺口继续保留在原任务中。
