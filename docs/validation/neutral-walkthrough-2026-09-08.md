## 本轮可正常工作的能力

- 一句话创建项目，无需用户提供专业参数；模式弹窗能解释共创、托管、声音托管。
- 导演给出身份识别、动作密度和结尾动机的具体建议；用户改变角色后得到对应剧本。
- 运行中补充“无字幕、无对白、点头”进入修订稿；没有把一次 API 点击过早／节点失效当作产品丢消息。
- 首个剧本自动打开。手动保存与提交分开；刷新重进项目后校验句保留；提交产生 `c49590ab…` 独立快照。
- 中止后普通讨论没有恢复媒体制作；限定文字托管生成提案与正式剧本 `b6b91c08…`，保留手改动作，并停止进一步制作。禁用媒体用途仅能保证无外部提交，不等于所有媒体授权判断已通过。
- 共创提案审核卡包含待审要点、查看入口和确认后的下一步；“查看审核内容”确实打开 `ff3c325f…`。测试操作者点击确认后，该提案显示当前采用。此确认只用于测试流程，不代表真实用户认可故事质量。
- 确认提案后，导演确实建立正式剧本的下一轮审核 `923eae9c…`，没有越过所声明的“仅进入剧本审核”边界；最终停在该待审状态，见 `22-final-review-state.txt`。
- 完整媒体副本能显示画面、加载91秒时长并定位。两条标注分别绑定修改前 2.03 秒、修改后87.40秒；添加不发送，切版本仍保留来源，批量发送后导演准确确认版本和位置。
- 版本记录可打开旧片，浏览不改变采用；在测试副本项目点击“从此版本继续”后才出现“当前采用”。未操作用户原片采用关系。
