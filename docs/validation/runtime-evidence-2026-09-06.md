## 真实 LLM 结果与边界

已执行首批 24 个真实 LLM 用例及 4 个语义回归用例，媒体工具使用明确标记的受控任务；部分检查另调用真实 GLM 读取既有真实片段。逐例回执位于 `local-data/llm-validation/<case>/receipt.json`。受控请求没有调用媒体生成接口。

- A1 三种模糊输入均给出创意与问题，没有生成媒体；故事吸引力待人评。回答有时仍偏长。
- B1 三种“先讨论，不生成”均未提交媒体；三种自然语言批准均记录到对应提案及实际用户消息，随后发布正式剧本、等待下一轮审核，无媒体调用。
- B2 限定托管到剧本的用例自动记录剧本采用并停止，没有扩展至媒体。
- B3 部分声音托管只提交一个受控配音请求，没有图片／视频。回复对受控任务建议“放行”不适用于真实产品，不能据此宣布整条部分托管体验通过。
- A2 包含两人、舱内到冰面、先结果后过程的约束，已形成提案，待人评。
- A3 保存未生成、提交后真实模型给出理解与意见；但把“人物不再说话”扩成“全片沉默”，并添加母亲遗言动机，保留为语义偏差。
- F1 三种表述中，一例把“3.2 秒处”解读成“尾部 3.2 秒”；其他例能覆盖两条意见，但有过度推断独立声音可用性的问题。场景族不能判为通过。
- C3 使用用户转述的冲突助手报告作为受控输入；导演识别人物数／性别与无文件成片的矛盾。未验证真实子 Agent 相互矛盾的完整交接。
- C1 补充复杂表述确实触发视觉和后期委派，最初各一次通信失败，导演重新委派后成功整合剧本并交审核。未生成媒体，过程约 179 秒；这是一次证据，不代表协作普遍稳定。

针对 A3／F1 加入范围和位置提示后，另执行 A3 一次、F1 三种原表述回归，均未生成媒体。A3 开始区分人物沉默与录音是否保留并提出问题，但对母亲录音的因果仍有推断；F1 的明确“某秒处”表述按位置处理，含“前面0.8秒”这一歧义的原表述仍被解释为0–0.8秒范围。记录为改善及未解决语义风险，不把增加提示当作整体通过。

## 浏览器与恢复

浏览器使用实际 4318 运行版本和开发项目，未操作共创保留输入的用户审核。已检查：待审完整剧本与独立草稿分开显示、保存不制作、明确提交形成实际文字快照、2 秒和 8 秒两条标注回流并统一发送、标注绑定源版本。最终检查未记录页面错误。截图与回执在 `local-data/browser-validation/`。

首次自动化检查误用了被页面 CSP 拒绝的动态等待表达式；改为正常 DOM 属性读取。第二次断言早于界面刷新，但后端已正确保存两条标注；等待实际 DOM 后继续，未把测试脚本问题报成产品丢失标注。

真实任务运行期间，《驻留》通过页面接收讨论消息并中止。尚未提交的任务停止；云端已有任务继续查询，结果保留候选。未调用 H3 DELETE。已复核重启后的取回与候选保存。最终通过页面采用正确的历史720P版，再恢复Fast修改版，确认采用身份、草稿保留、未新增媒体任务及无页面错误；回执为 `history-adopt-receipt.json`。历史继续创作的长期分支体验仍需更多使用验证。

### 已发现并修复的工程问题

1. H3 参数写成 `seconds`／`1080p`，以及结果不明时换请求身份和 Provider 重试：适配器提前校验；稳定 `unit_id` 约束未决任务，不能绕过。
2. 任务已成功生成但本机代理 fake DNS 被下载检查误判，导演误发补拍：区分生成、查询与下载失败，优先取回现有结果；仅两个已观察 Provider CDN 允许经用户配置的回环 HTTPS 代理解析，仍拒绝本地目标、任意域名及重定向。重复候选保留并计入调用记录。
3. 直接使用未批准剧本、把视频伪装成参考图阶段、迟到产物回滚新稿：按具体依据与用途复核；历史恢复为明确操作，旧专业任务保留原始依据。
4. 消息／审核已保存却未投递导演：在同一事务保存待投递输入；后台唤醒补投，专业结果与媒体结果同样处理。中止时的媒体通知等待继续，讨论失败不吞掉未投递结果。
5. 审核显示错稿、保存与提交竞态：展示准确审核快照；独立草稿记录来源与修订，提交等待最新保存，冲突保留双方内容。
6. 短声音淡出按全片结尾计算：已改用音轨实际或裁剪长度；FFmpeg 测试核对尾部能量下降。基础变速同步处理原生混合声并保持音高。
7. Ark HTTP 200 的任务终态失败中带 `error`，过去错误进入 query_failed：查询仅接受身份匹配的终态回执，保存安全失败类别，内容审核拒绝不会触发相同内容的跨模型重试。
8. 标题声称备选模型而实际使用主用，以及用途修改后旧pending任务仍可能新发POST：工具必须声明准确型号，入队和真正POST前均核对；已提交任务不受新配置影响。
9. 导出派生和补拍时漏独立台词、重复原生声：保留原剪辑的专用导出操作和原生混音来源检查；已取得声音修正前后影片和解码比较。

H3 原始未知提交仍保留 unknown，没有因列表中暂未发现就伪装为确定失败。旧记录未保存具体连接错误类型，无法补写成“确定未发送”。新请求区分建连前失败与响应丢失。

## 耗时、用量与费用

`scripts/export_validation.py` 从实际数据库导出不含凭据、提示词或签名地址的项目摘要，包含各次任务、Provider 身份、用量、起止时间、状态、引用数量和剪辑复用身份。导出到 `local-data/validation-export/`。例如：

```powershell
uv run --frozen python scripts/export_validation.py --project <项目身份> --output local-data/validation-export/project.json
```
