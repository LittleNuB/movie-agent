## 已交付

- 对话为中心的三栏工作区，项目搜索与实际重命名，可收起导航与作品侧栏；多标签每次显示一份作品，侧栏可拖动及键盘调整。
- 支持标题、列表、编号、引用、HTTP(S) 链接、代码及简单表格的文字排版，保留内容转义；不是完整富文本编辑器。作品入口采用紧凑链接。
- 真实模型请求、工具准备／执行／完成、专业任务和后台媒体状态。运行详情实时更新并持久化；模型多次调用分别记录。工具返回不等于云端生成结束，累计调用 tokens 不表示当前上下文占用。
- 已接收、处理中、已处理消息状态；按项目保留未发送文字；发送失败可重试，已送达后的刷新失败单独说明。流式正文持久化，断线重放带偏移，避免刷新清空或重复拼接。
- 历史与待审剧本展示各自原文；独立“剧本草稿”保留手改，保存、提交和冲突有持续状态。输入法组字时延后整体刷新；阅读位置、播放节点与页面内切换后的进度保留。
- 全部作品按名称与类型筛选，显示时间和采用状态；真实影片、图片、声音与母版可打开。标注跳转源版本时间，批量和逐条发送继续沿用原绑定关系。
- 共创／托管、等待审核、媒体暂停分别呈现；系统／日间／夜间外观，桌面 1366 与 1600 宽度。

## 真实导演验证

4322 隔离实例沿用本机 GLM 5.3 Flash 连接及 Windows 凭据管理器，仅分配导演／视觉理解用途，未配置媒体用途。通过产品界面发送地铁陌生人创意，要求读取项目、实际改名为“末班来客”、给出建议并提一个问题，不写正式剧本或生成素材。

## 审查

Standards 轴发现重启缺失消息导致启动失败、失败与中断混淆、基础格式化函数重复。已分别修复；其中重复属于维护建议。Spec 轴发现已送达误报发送失败、键盘调整后丢焦点、常用 Markdown 不全。复核又发现标签与对话作品链接共享身份导致焦点错位，修复为按控件角色定位，并通过标签 Enter 操作断言。相关路径均已复核。未用审查代替电影人评。
