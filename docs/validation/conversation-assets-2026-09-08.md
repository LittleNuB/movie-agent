# 对话资产库验收

2026-09-08，用户通过两张截图指出过程产物及完整任务列表挤占对话，明确要求每段对话有专属资产库承接中间产物，同时对话仍能看到产物入口。本项在前端工作区基线 `216c8ed` 上实施。

## 实际行为

- 顶部和作品侧栏提供“资产库”入口，右侧固定保留资产库标签；单个资产仍以独立标签打开，同一时刻显示一个标签。
- 数据来自当前电影项目的全部产物；当前一个电影项目对应一段创作对话，不跨项目聚合，不仅列出最近或已打开的资产。
- 分类包括文稿、图片、视频镜头、声音、成片与母版；支持名称、类型及 ID 搜索，展示图片缩略图、创建时间、实际记录的时长／尺寸和采用状态。搜索、分类及已打开标签按项目保留。
- 对话只保留最近三项的入口与资产总数；完整中间产物和历史版本均可在资产库访问。新增产物沿既有 SSE 更新资产库，不自动抢走当前标签或清空筛选。
- 媒体任务在对话中显示一行摘要，完整状态、失败原因和恢复入口位于“运行记录 → 媒体任务”。失败且没有产物的任务不作为资产列出；受阻计数保留历史事实，不等同于当前仍需重拍。
- 查看、搜索和切换均不等于采用、审核或生成；手改草稿继续独立保存。导演的界面说明同步到新入口名称。
