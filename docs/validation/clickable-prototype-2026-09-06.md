## 实际结果

| 检查路径 | 结果与可证明的行为 |
|---|---|
| 首屏与新建 | 示例只填入文字，首条发送才创建项目；无需素材 |
| 模型设置 | 示例凭据只读；模拟成功与失败均可查看，未保存凭据或发请求 |

| 侧栏与标签 | 两侧可收起；新内容保留主动关闭／查看选择；作品在独立标签切换 |
| 异常与项目切换 | 普通文字说明模拟失败，自然语言继续；切换影片后仍保留草稿和对话 |

| 页面停止边界 | 刷新停止上一次页面计时并明确说明，没有宣称后台持续完成 |
| 全权托管 | 从首次提案经过示例剧本、视觉、试拍和完成；无越权地改变用户正在查看的作品 |
| 本地服务范围 | 前端文件允许清单之外返回 404；测试过程零外部浏览器请求、零未捕获 JavaScript 异常 |
