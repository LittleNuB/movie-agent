# ADR 0006：H3 768P 与 Seedance Fast 720P

Status: Accepted

Date: 2026-09-06

用户最新要求：“后续 H3 统一用 768P，Seedance 后续统一用 Seedance 2.0 fast，用 720P”。此项取代 [ADR 0005](./0005-720p-production.md) 中所有新视频统一 720P 的生成限制，保留其 720P 导出和历史保护要求。

- H3 新请求默认且统一为 `768P`，不再提交 `2K`。
- 本轮个人方舟视频模型改为 `doubao-seedance-2-0-fast-260128`，新请求统一 `720p`。模型 ID 已由当前连接真实 `GET /models` 返回核对；发现模型不等于生成验收通过。
- 保留 H3 主用、Seedance Fast 备选的个人用途分配。H3 最近实际返回 HTTP 402 的事实保留供导演判断，不充值、不假定账户问题已消失。
- 参数在实际提交前复核，历史任务继续使用其原始模型和外部身份查询，不能把旧标准版任务当作 Fast 结果。
- 成片为 1280×720、16:9、24 fps、48 kHz；生成源分辨率独立记录，原文件不覆盖。
- 模型 ID 属于本机个人配置，产品初始连接、模型、用途仍为空。

依据：用户本次最新指令；当前方舟连接模型目录的实际只读回执；[Seedance 2.0 官方论文](https://arxiv.org/abs/2604.14148)对 Fast 变体和视频能力的说明。实际账号权限与影片效果分别记录。
