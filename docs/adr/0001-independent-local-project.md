# ADR 0001 · 独立仓库与 Windows 本地个人部署

Status: Accepted

Date: 2026-09-06

## 背景与决定

新的 AIGC 电影产品与旧后期工程已有不同的用户入口、制作路径和运行框架。所有者要求建立独立仓库，并选择本地加私有 GitHub 的方式。

- 仓库为 LittleNuB/movie-agent，默认分支 main，私有。
- 首版正式支持 Windows 本地个人部署，通过电脑浏览器使用；macOS／Linux 与手机完整创作后续适配。
- 本机运行 Agent、任务管理与项目存储，生成调用云端模型 API。用户自备 API Key，由设置页引导配置并检查连接。
- 关闭页面不自动中止已授权制作；本地服务停止、电脑关机或休眠时，本地调度无法继续。云端已提交任务按实际状态核对和恢复。
- 旧工程及未提交改动保留，新仓库不继承其 Git 历史、应用代码和运行数据。

## 影响与未决定事项

本次不建设多人在线账号服务。安装分发、系统具体版本、硬件要求和可靠恢复机制在后续任务确定与验证；当前没有可运行安装包。

私有建仓、初始化提交和推送已获授权。开源许可证和公开发布另行确定。建仓后承接已批准的可点击原型任务，无需再次询问是否开始。
