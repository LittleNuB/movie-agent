# ADR 0004 · 模型选择属于用户配置

Status: Accepted

Date: 2026-09-06

## 依据与决定

所有者审阅可点击原型后明确指出：此前选择的模型是自己使用时的选择，不是完整产品的预设；设置页应采用常见的 API 填写方式，不预设某种模型。

产品初始没有服务商、地址、模型或用途分配。用户先添加服务连接（名称、接口类型、Base URL、API Key 或无需 Key），再添加模型 ID，最后选择不同创作能力使用哪个模型。一个连接可管理多个模型，多个连接可并存。

GLM 5.3 Flash、MiniMax H3、Seedream 5.0 Pro 和 Seedance 2.0 继续作为所有者个人使用与首轮验证的选择，保留历史接入证据；不自动填入新用户配置，不作为唯一支持列表或不可替换的产品依赖。

## 取代范围

取代旧模型设置中四个固定厂商／模型栏位，以及设计、产品和配置示例中将上述选择理解为产品默认值的表述。不撤回个人选型或改写历史验证结果；不改变 AgentScope 首选和 ViMax 领域复用方向。

## 能力边界

通用表单不等于任意 API 即填即用。真实调用须有相应协议或 Provider 适配器，并验证工具调用、图片、视频、声音的具体能力。列表可获取时允许发现模型，也支持手动填 ID；获取列表或连接成功均不能证明全部能力通过。

本轮仅更新交互原型：模型检查和获取是模拟，Key 可编辑、默认遮罩且仅留页面内存，非秘密配置可保留到浏览器；正式凭据保存和后端检查仍待实现。详细结构见[模型与 API 设置](../product/model-settings.md)。
