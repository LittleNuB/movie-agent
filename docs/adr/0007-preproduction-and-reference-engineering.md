# ADR 0007 · 剧本制作说明与参考资产工程

Status: Accepted

Date: 2026-09-09

## 决定依据与关系

所有者阅读[生成质量研究](../research/generation-quality-2026-09-09/report.html)后明确同意，要求“这轮的决策先形成文档，再继续推进”。本决定补充 [ADR 0002](./0002-runtime-and-domain-reuse.md) 与 [ADR 0003](./0003-creative-control-and-evidence.md)，将能力建设重心前移到可拍摄设计和参考工程；不替代既有创作授权、产品模型配置或生成规格。

研究报告保留原研究状态和证据边界；只有本 ADR 中列出的选择转为当前基线。未实测的模型收益、账户能力、Context-IR 和论文结果不因本次接受自动变成产品能力。

## 已接受的选择

1. **从剧本形成制作说明。** 用户继续阅读和手改正常剧本；Agent 在其后记录人物／地点／道具身份、世界规则、关键事件前提、人物动机、行动、结果、状态变化及画面／声音如何传递信息。每份说明绑定具体剧本版本，区别用户要求与创作补充。不强制三幕、固定角色或镜头数。
2. **做有限、可解释的逻辑审查。** 指出位置、缺失前提与表达问题，允许有意留白、开放结尾和非线性叙事。运行时不增加趣味评分或自动评分改稿循环；故事吸引力与价值仍由人评。
3. **建设参考资产及其关系。** 人物主形象、服装、场景、道具状态、镜头构图根据剧情需要生成。必要侧背视角从可靠主参考派生，不能用多次无关联文生图代替身份继承。记录用途、状态、来源、父参考、检查依据及使用镜头。
4. **保存多视图与调用时选图分别处理。** 不要求每个角色都生成三视图，也不默认把多视图拼版传给视频模型。每份输入参考有明确作用；当前个人 Seedance 2.0 Fast 路线优先遵守其面部／全身参考建议，额外视角按任务验证。Provider 参数与输入模式由程序校验。
5. **保护标准参考。** 生成完成仅形成候选。可作为标准或补充的参考要有记录的检查依据；新生成画面不自动覆盖标准。合理衣着、伤势、道具变化形成状态版本，不能被机械纠正回最初外观。
6. **从镜头规格编译实际请求。** 镜头明确叙事作用、人物／空间／道具状态、起止构图、动作、运镜及声音。模型选择文生、首尾帧或多模态路径；程序解析真实资产身份、锁定版本、检查依赖与 Provider 能力，保存实际调用依据。
7. **引入带临时声音的分镜预演。** 在整片高成本生成前，使用粗分镜与临时声音验证信息顺序和节奏，清楚标识预演。沿用右侧作品页，不新增完整时间线工作台；预演不算真实动态试拍或成片通过。
8. **按参考依赖安排制作。** 可先制作更适合建立可靠参考的内容，再按叙事顺序剪辑。代表性试拍针对实际难点。生成后继续读取真实产物并局部修复，不仅检查 API 成功。

## 架构与产品边界

- 沿用 AgentScope、主导演与按需专业职责、后台媒体任务和对话资产库；本次不决定增加 Agent 数量或更换框架。
- 首批模块为剧本制作说明、参考资产与依赖管理、镜头输入编译；随后接分镜预演与重点质量检查。方法可以按需加载为 Skill，但仅添加提示词不算工程能力完成。
- 专业信息默认由 Agent 组织，用户无需填写专业表单。共创沿用关键审核，托管在授权范围推进，不为每张图增加审批。
- 保存、提交、批准和实际生成保持独立。旧数据不自动补造说明，不重写采用关系；复用旧资产时显式说明来源和适用状态。
- H3 768P、Seedance 2.0 Fast 720P及成片720P的个人规格继续有效；产品模型默认仍为空。
- 保留原始产物和模型来源，按实际 Provider 的素材引用机制处理；不假定加工过的肖像或跨平台素材一定可引用。
- ViMax 为优先代码起点；AdCraft、OpenMontage 提取方法与模块时核对固定版本许可。Context-IR、3D预演及需要改模型权重的方案保留为候选，未批准直接纳入首批运行依赖。

## 验证与代价

先分别比较剧本设计和参考工程，保持创意、模型、规格等可控条件；真实调用与人评分别记录。增加前期图片和预演成本，需与视频返工减少一起核算；不设置新的费用或时间硬停止阈值。旧失败和用户人评不改为通过。

实施顺序、检查范围和实际状态见[前期制作能力建设](../plans/preproduction-quality.md)。
