# ADR 0008 · 仅保留共创和托管

Status: Accepted

Date: 2026-09-09

## 决定与取代关系

用户查看“共创 · 声音托管”选项后，明确要求取消，仅保留共创和托管。本决定取代 [ADR 0003](./0003-creative-control-and-evidence.md) 中的部分托管条款，其余版本保护、具体授权和证据边界继续有效。

- 共创为默认，关键产物与修改方案由用户确认；声音方案不再拥有专用自动批准路径。
- 托管在用户已授权的任务范围内自主推进，仍支持插话、中止和改为共创。
- 界面、REST输入、项目写入和导演提示仅使用 `co`、`auto`。不把声音托管藏到自然语言入口。
- 已有 `audio` 项目在数据库打开时事务性改为 `co`，发送项目状态事件；不新增导演输入、不启动制作。迁移重复运行不再产生变化。
- 历史产物、草稿、批准和任务原始授权记录保留。新任务使用当前模式；已提交的云端任务继续遵循既有查询、取回和版本保护。

旧原型与研究／验收快照保留当时行为，不能再作为声音／部分托管仍受支持的依据。正式运行入口的行为以本决定为准。

## 实施与验证

已移除真实前端第三选项、API枚举和后端声音专用审核路径，增加旧项目迁移。聚焦验证覆盖旧项目内容保留、迁移幂等性、共创声音审核、托管采用及API拒绝旧模式；不调用真实模型或生成媒体。

2026-09-09 检查：19项授权、API与存储测试，Ruff、3项前端测试与语法检查通过。全量检查中的新迁移用例首次因测试夹具遗漏审核的产物身份失败，补齐夹具后聚焦复核通过，其余57项在全量检查中通过。4325实际页面刷新后，模式弹窗只有2个选项：共创、托管；未应用模式切换或发送消息。服务重启前两个验证项目均无未处理输入或活动任务，生成额度仍为9/10。
