# ADR 0009 · 公开源码与开发预览发行

Status: Accepted

Date: 2026-09-09

## 授权与决定

用户要求将当前内容打包、同步 GitHub、开源仓库并写清 README。本次发布采用 MIT 许可证；当前实现同步到 `LittleNuB/movie-agent` 的默认分支 `main`，仓库改为公开，以 `v0.1.0-preview.1` 标记首个源码预览版本。

此决定取代 [ADR 0001](./0001-independent-local-project.md) 中的私有发布和许可证待定条款；独立工程、Windows 本地个人部署及数据保护要求继续有效。原型和实现分支保留，历史研究与早期验收按其日期理解。

提交作者信息也会随历史公开。用户经明确提示后选择保留原提交信息，因此不改写作者、提交编号或历史。

## 公开范围

- 当前受版本控制的应用代码、前端、脚本、锁定依赖清单、测试、设计研究和经过检查的文档图片。
- 项目 MIT 许可和第三方来源／许可声明。第三方依赖继续适用各自许可；FFmpeg 二进制不随源码发行。
- 基于 Git 提交生成的源码 ZIP 和 SHA256 校验文件，使用 GitHub prerelease 标识开发预览性质。
- README 区分工程实现、分项真实验证、开发者干预和未通过的人评；不将当前状态宣传为稳定自主完成电影。

个人配置、凭据、会话、数据库、缓存、依赖环境、原始生成素材和影片均不发布，也不从旧工程补入代码或运行数据。原提交作者信息按上述明确选择保留。

## 核对方式

公开前检查受版本控制文件、可达历史、文档图片、链接和许可；执行必要的代码检查和空配置启动检查。线上核对仓库可见性、默认分支、提交一致性、README 渲染及发行资产。实际预检见[发布检查](../validation/public-release-2026-09-09.md)，具体发行提交与下载校验和以 GitHub Release 为准。

发布源码不新增真实电影制作、人评通过或付费调用的结论。后续创作质量和 UI 工作沿用既有任务继续推进。
