# 历史资料

这些材料解释早期思考与证据出处。日期、当时的检查结果和被撤回的结论保持历史语义，不能用来覆盖[当前设计](../../DESIGN.md)。

| 材料 | 原始用途与限制 |
|---|---|
| [2026-09-04 产品早期稿](./2026-09-04/product-early-draft.md) | 含旧范围和方案假设，后续决定已替代其中多项 |
| [2026-09-04 技术早期稿](./2026-09-04/technical-early-draft.md) | 含旧工程保留、固定运行图、费用停止等已撤回假设 |
| [来源台账](./2026-09-04/research/claim-ledger.md) | 保存当时来源与用户决定快照；模型、费用和赛事信息可能过时 |
| [证据缺口矩阵](./2026-09-04/research/gap-matrix.md) | 初轮研究缺口，不替代当前验证矩阵 |
| [综合底稿](./2026-09-04/research/report-source.md) | 早期论证，不作为现行实施规格或比赛日期承诺 |
| [初轮读者检查](./2026-09-04/research/reader-check.md) | 历史文档检查，不代表产品验收 |
| [2026-09-05 文档归并检查](./2026-09-05/document-review.md) | 旧工作区读者检查，早于后续架构与前端决定 |

当前目标时长 90–120 秒，默认共创、支持托管，费用目标不设硬上限，Agent 数量不固定，Windows 本地个人部署。旧 v0.3／v0.4 后期工程仍保留在原仓库；其实现、历史设计和 Ticket 未迁入本仓库。

迁移来源与文件哈希见[来源记录](../provenance/source-migration.md)。历史资料新增迁移提示并修复链接，不将其结论重写为当前已通过。
