# Movie Agent · 可点击交互原型

这是可整体舍弃的交互原型，保存在 `prototype/film-creation` 分支。它验证 A／B 主题和三栏创作操作如何配合，未实现真实导演、模型接入、媒体生成或后台电影任务。

## 启动

使用 Node.js 24，在仓库目录运行：

```powershell
npm run dev
```

打开 [本地页面](http://127.0.0.1:4317)。没有 npm 运行依赖，无需 `npm install`。服务只监听 `127.0.0.1`，只允许读取七个前端文件，不提供模型代理、文件上传或项目目录服务。按 Ctrl+C 结束服务；可用 `PORT` 环境变量调整端口。

## 建议体验

1. 首屏点击灵感示例，文字只填入输入框；发送才建立影片。模型设置中自行添加 API 连接、模型 ID 和用途，体验模拟检查及模型发现。原型请填写示例内容，产品不预设厂商或模型。
2. 打开《最后一束光》，查看剧本、视觉方向和动态示意。底部模式菜单支持共创、声音部分托管、全权托管。
3. 修改剧本。保存只保留草稿；提交后看导演建议，点击“查看内容”检查准确的提交快照，确认后才演示制作。
4. 播放预览、拖动时间、添加标注。标注进入输入框后仍可修改或移除，可以逐条发，也可以带整体要求一起发送。
5. 打开历史版。浏览不会切换采用版本；“从此版本继续”保留历史和未提交手改稿，手改稿可恢复到剧本编辑器。
6. 制作过程中发消息或中止。右上角“演示选项”可模拟异常；在普通对话中回复“继续”恢复示例流程。

自然语言仅识别少量演示表达，如“同意”“继续”“切换到共创”“托管”“声音托管”“应用改稿”和声音修改意见；其余文字进入通用示例反馈。新影片沿用固定示例故事，不对输入做真实创意推理。

## 保存与媒体边界

主题、项目、草稿、版本和标注保存在当前浏览器、当前地址的 localStorage。清除站点数据、更换浏览器或端口不会自动迁移它们；本原型无跨标签页并发同步、账号或数据库。文本草稿可下载备份。请使用示例内容。

切换项目时，当前页面的示例计时继续。关闭或刷新页面后，恢复已有内容并停止上一次计时；界面会明确说明，不假装后台完成电影。真实任务状态与恢复仍待后端实现。

预览由 [film-art.js](./film-art.js) 原创绘制，100 秒时间轴展示轻微运动、日出与字幕；声音为浏览器合成低鸣。其作用是验证播放和时间点反馈，不是影片画质、配音、配乐编辑或生成连续性的验收。

## 检查

```powershell
npm run check
python prototype/verify.py
python prototype/verify_settings.py
```

后两条需另有 Python Playwright 与 Chromium，并先运行本地服务；它不是启动原型的必要依赖。第二条检查创作流程，第三条检查设置、配置引用与凭据不持久化。截图和结果写入忽略的 `.cache/prototype/`。核心证据及交互限制见[初版验证记录](../docs/validation/clickable-prototype-2026-09-06.md)与[设置调整记录](../docs/validation/model-settings-2026-09-06.md)。

代码按静态服务、示例数据、界面行为、样式和原始绘图分开。为便于舍弃，未建设生产框架、Provider 抽象、运行 API 或数据库 Schema；后续真实应用应重新审视这些边界。
